# 随便听听 (suibian-listening)

MusicFree 插件：多平台官方榜单「无限随机」播放，聚合网易云、酷我、QQ 音乐的官方榜单歌名，按「歌名 + 歌手」搜索 bilibili 并直接播放，支持歌词自动获取。

## 功能

- **22 个官方榜单**：网易云（热歌/飙升/新歌/抖音/怀旧金曲）+ 酷我（热歌/飙升/新歌/网络/夜店/经典等）+ QQ 音乐（巅峰榜·流行指数/热歌/新歌/欧美/内地/港台/韩国/日本等）
- **无限随机**：`无限随机·随便听听` 列表每页 100 首、`isEnd` 恒为 `false`，播到列表尾自动加载下一页随机新歌，跨页按「歌名+歌手」去重；歌曲池耗尽后自动重置去重记录继续随机，不会永久停播
- **智能播放**：用「歌名 + 歌手」搜索 bilibili，先排除短片/合集，再按评分排序选最优结果，多页搜索提高命中率
- **歌词自动获取**：基于 LRCLIB 开放歌词库，按歌名 + 歌手自动匹配 LRC 时间轴歌词，无需手动搜索
- **附赠搜索**：支持按歌名搜索（数据源为网易云）

## 安装

1. 下载 `suibian-listening.js`
2. MusicFree → 设置 → 插件管理 → 导入插件 → 选择该文件
3. 进入插件 → **排行榜** → 点 **「随便听听 / 无限随机·随便听听」** 开始播放

## 说明

- 歌曲信息来自各平台官方榜单，仅供展示；**播放地址由插件实时搜索 bilibili 解析**，不依赖额外音源
- 歌词由 LRCLIB（lrclib.net）提供，免费开放歌词库，无需登录/会员
- 播放失败时若已安装其他音源，可在 **设置 → 基本设置 → 播放失败时尝试更换音源** 开启，作为兜底
- 榜单/接口均为非官方公开接口，可能随平台调整而失效；失效时更新 `SOURCES` 数组中的榜单 ID 即可
